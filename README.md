# Random Quote Generator

**Автор:** Еганшин Равиль Сергеевич

## Описание

Простое и удобное GUI-приложение на Python (Tkinter) для генерации случайных цитат.  
Поддерживает:
- Генерацию случайных цитат
- Добавление новых цитат
- История всех сгенерированных цитат
- Фильтрацию по автору и теме
- Сохранение истории в JSON
- Валидацию ввода
